## 27. Pour chaque région, quelle filière a le plus produit en 2019 ?

```sql
WITH s AS (
  SELECT region, source, SUM(mw) * 0.5 AS energie_mwh
  FROM (
    UNPIVOT (
      SELECT region, thermique_mw, nucleaire_mw, eolien_mw, solaire_mw, hydraulique_mw, bioenergies_mw
```
